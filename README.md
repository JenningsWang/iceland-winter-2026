# 冰岛冬行地图 · 2026.12.05–12

一份中文交互式冰岛冬季自驾攻略。左侧是真实地理地图，右侧联动每日路线、景点、住宿、备选和完整出行细节。

**在线访问：[冰岛冬行地图](https://jenningswang.github.io/iceland-winter-2026/)**

已于 2026-10-26 发布并验证。打开网页后，点击地图、日期或 H 图钉查看详情；右上角「完整攻略」可阅读全部内容并打印 / 保存 PDF。

所有住宿默认为 **正在预定**。酒店例子只是位置参考；没有声称已订、空房或具体价格。住宿图钉是区域占位。

## 功能

- 71 个地标：24 个已规划点及行程节点、24 个沿线备选、23 个全国参考。
- 8 天真实道路几何，以及斯奈山 574 西端可选绕行。
- 行程身份与冬季可达性独立标记和筛选。
- 点击景点、路线、H 住宿图钉或日期，打开右侧相应细节。
- 搜索中文地名、当地名称和地区。
- 住宿状态、酒店名称、地址、备注、地图坐标可在本设备编辑。
- 住宿 JSON 导出 / 导入；共享文件位于 `data/bookings.json`。
- 完整攻略阅读与打印 / 保存 PDF。
- 日期、景点、住宿可通过 URL 的 `#day=...`、`#point=...`、`#stay=...` 分享。
- 桌面左右布局；手机地图在上、详情在下。
- 海岸线、公路、路线及攻略随网页打包，默认无需外部地图 API。在线街道底图可选择叠加。

## 本地验证和构建

需要 Node.js，无需安装 npm 依赖。

```bash
npm run check
npm run build
```

`dist/` 是可发布的静态站点；构建同时生成单文件 `iceland-winter-2026.html`，可直接在浏览器打开，用于离线审阅。在线路况、来源、导航与可选街道底图仍需要网络。

## 发布到 GitHub Pages

仓库：[`JenningsWang/iceland-winter-2026`](https://github.com/JenningsWang/iceland-winter-2026)。已配置 GitHub Actions 自动发布。以下步骤供迁移或重新部署时参考。

1. 把源码放入该账号新仓库的 `main` 分支。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 提交代码或手动运行 **Publish Iceland winter guide** 工作流。
4. 等 `Deploy` 成功后，以 GitHub 返回的 Pages URL 为准。

工作流在 `.github/workflows/pages.yml`，会先验证数据、构建，再发布 `dist/`。所有站内资源使用相对路径，适合 GitHub Pages 项目子路径。

**不能只上传 ZIP 文件本身。** GitHub Pages 需要仓库内可直接读取的网页与资源，或者该项目的源文件与构建工作流。

每次更新 `main` 分支都会先校验再发布。工作流结果可在仓库的 **Actions** 页面查看。

## 后续怎样更新酒店

1. 网页点击 **住宿** 或 H 图钉，填写信息，选择 **保存到本设备**。
2. 在住宿列表点击 **导出住宿更新**，得到 `bookings.json`。
3. 另一台设备可通过网页 **导入更新** 使用该文件。
4. 如果需要所有访问者都看到更新，把文件替换到仓库的 `data/bookings.json` 并提交。Pages 会重新部署。

本设备已保存的记录优先于共享文件。网页没有后端账户、订房接口，也不会替用户提交酒店订单。

## 时间与可达性边界

资料核验日期：**2026-10-26**。驾驶预算不含游览、用餐和冰洞向导转运，不是暴风雪、封路或改道情况下的上限。冬季分类不能当作未来日期的实时通行承诺。

冰洞图钉只表示 Jökulsárlón 集合区域；洞口不是固定点。Reynisfjara 已按 2026 年侵蚀公告保守描述，12 月以当日开放区域和现场指引为准。

斯奈山核心往返路线约 430 km，冬季驾驶预算 **7–8 小时**；经 574 绕西端约 450 km，不能视作所有天气下都可走的替代。
